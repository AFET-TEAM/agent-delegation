# PR Standards Skill

## Purpose

Standardize how changes are presented for review and release.

## A Good PR Includes

- concise summary
- why the change exists
- validation evidence
- risks and migration notes
- follow-up items if scope was intentionally limited

## Example Outline

```text
Summary
Validation
Risks
Follow-up
```

## Reviewer Goal

A reviewer should understand impact, validation, and residual risk quickly.
