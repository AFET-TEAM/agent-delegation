# Project Context Discovery (PCD)

## Okuma Önceliği

1. README
2. package/manifest/build config
3. docs/
4. ADR/plan dosyaları
5. giriş noktaları
6. ilgili modül klasörleri

## Çıktı Formatı

- amaç
- ana modüller
- kritik bağımlılıklar
- riskler
- bilinmeyenler
- önerilen okuma listesi

## İyi PCD Özellikleri

- kısa ama yönlendirici
- tüm repo yerine görevle ilgili yüzeyi açığa çıkaran
- sonraki okumayı daraltan
