# PR Standards

## 1. PR Quality

A good PR summary explains:
- what changed
- why it changed
- how it was validated
- risks or migration notes

## 2. Scope

Keep PR focused. Avoid mixing unrelated changes.

## 3. Recommended Sections

- Summary
- Validation
- Risks
- Follow-up

## 4. Reviewer Ergonomics

Give reviewers enough structure to assess impact quickly.

## 5. When Relevant

Add screenshots, sample outputs, or contract notes when they materially reduce ambiguity.
