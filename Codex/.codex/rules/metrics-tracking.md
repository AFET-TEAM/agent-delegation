# Metrics Tracking Standards

## 1. What to Track

- token estimate vs actual
- tasks completed per agent
- review rounds
- fallback events
- repeated rework patterns

## 2. Why It Matters

Metrics calibrate task sizing, model selection, and skill loading.

## 3. Session End Requirement

At end of multi-agent sessions, update memory and metrics artifacts.

## 4. Usage Note

Metrics are feedback signals, not vanity numbers.

## 5. Escalation Signal

Repeated drift or repeated fallback should trigger calibration review.
