# Review Report Contract

Use this template for T4, T2, and T1 review outputs.

## Header
- Review ID:
- Date:
- Reviewer Name:
- Reviewer Tier:
- Expected Model:
- Actual Model:
- Item Under Review:
- Related Task / Session:

## Review Decision
- Decision: Approved | Revision Required | Rejected
- Severity Summary: Critical / High / Medium / Low counts

## Findings

### Critical
- none / list findings

### High
- none / list findings

### Medium
- none / list findings

### Low
- none / list findings

## Required Fixes
- list concrete changes required before approval

## Residual Risks
- list risks that remain even if approved

## Validation Notes
- what was checked
- what was not checked
- confidence level

## Escalation
- whether escalation is required
- who should take over if required
