# Task Report Contract

```markdown
## [Display Name] — Task Report

**Task**: [summary]
**Status**: Completed | Partial | Failed
**Files**: [paths]
**Model**: [expected -> actual]
**Confidence**: High | Medium | Low

### Details
- what was implemented/analyzed
- key decisions
- important constraints

### Validation
- tests/checks/review notes
- what was or was not verified

### Notes
- open risks
- escalations
- follow-up recommendations
```

## Rules

- keep details specific, not generic
- if validation did not run, say so explicitly
- if fallback occurred, mention it here and in session summary
