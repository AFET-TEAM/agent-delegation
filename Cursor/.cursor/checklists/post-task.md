# Post-Task Checklist

## Always
- summarize what changed
- surface open risks
- confirm whether review happened
- confirm whether fallback happened

## For Serious Sessions
- update a session summary using `.cursor/contracts/session-summary.md`
- update resume context if continuation is likely
- update fallback/token/performance metrics if applicable
- update active plan if open work remains
- preserve reusable lessons in learned patterns when justified

## Before Final Closure
- ensure no hidden rework or unresolved severity remains
- ensure git-consent rules were respected
- ensure final operator-facing summary is honest and actionable
