# SCSS Standards

## 1. Design-System Alignment

- prefer semantic tokens
- avoid hardcoded visual constants when a design system exists

## 2. Maintainability

- co-locate styles sensibly
- keep selectors readable
- avoid over-nesting

## 3. Anti-Pattern

Specificity wars and deeply nested selectors create long-term styling debt.

## 4. Good Practice

Use styles to support component boundaries, not to hide structural problems in markup.
