# Commit Standards

## 1. Consent Rule

No commit without explicit user git consent.

## 2. Format

Use conventional commits where commits are requested.

## 3. Scope

Keep commit atomic and coherent.

## 4. Bad Examples

- `fix stuff`
- mixed unrelated changes in one commit
- vague commit titles with no domain signal

## 5. Good Examples

- `feat(auth): add refresh-token rotation`
- `fix(notification): handle empty preference state`
